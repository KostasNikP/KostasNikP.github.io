# Konstantinos Nikolakopoulos — Developer Portfolio

A responsive, single-page portfolio built with plain HTML and CSS.

## Publish it with GitHub Pages
1. Create a new **public** GitHub repository named `kostasnikp.github.io` (if that name is available for your account).
2. Upload `index.html` to the repository's root.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
5. After GitHub Pages finishes deploying, the portfolio should be available at `https://kostasnikp.github.io/`.

If GitHub does not allow that repository name or the URL differs, use the Pages URL shown in repository Settings → Pages.

## Before submitting the application
- Open the site and verify every link.
- Check the displayed name spelling and update it if needed.
- The phone previews are illustrative CSS mockups, not screenshots of the real app.
- Confirm the project feature descriptions match the current GitHub repository.
