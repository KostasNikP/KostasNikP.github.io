03Project

ShopApp

Flutter 3.x · Dart · Provider · Android / iOS / Web

A cross-platform e-commerce application for Android, iOS and Web, built with Flutter 3.x and Dart. It covers the complete purchase flow, from sign-in to checkout.

  • Authentication and session management with Provider
  • Real-time product search, category filters and ratings
  • Shopping cart with live totals and an animated checkout / payment flow
  • MVC-style structure, persistent state και Dark / Light theme
  • Third-party Flutter packages for card input, ratings and filtering
